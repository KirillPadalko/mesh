### 1. На сервере (КРИТИЧНО - сделать ПЕРВЫМ)

- [x] `main.py` - WebSocket keepalive настройки


**Ожидаемое время:** 5-10 минут сборка + время распространения

## 📊 Проверка после применения

### Проверка сервера:

1. **Логи не содержат 10-сек задержек:**
```bash
docker logs --tail 100 mesh-server-container | grep "already connected"
```
После каждого "already connected" должен быть "registered" в течение 1 секунды

2. **Активные соединения соответствуют реальности:**
```bash
curl http://localhost:8000/stats
```
Количество должно быть разумным

3. **Offline messages минимальны:**
```bash
docker exec mesh-server-container sqlite3 mesh_graph.db "SELECT COUNT(*) FROM offline_messages;"
```

### Проверка клиента:

1. **TURN серверы работают (логи):**
```
adb logcat | grep "WebRtcManager"
# Должны видеть: "Adding TURN server candidates"
```

2. **Аудио вызов работает:**
- Позвонить между двумя устройствами
- Проверить что слышно в обе стороны
- Логи: `Audio track enabled for <peer>`

3. **Сообщения доходят стабильно:**
- Отправить 10 сообщений подряд
- Все должны дойти без задержек
- Переключить WiFi -> Mobile -> WiFi
- Сообщения продолжают доходить

## ⚠️ Возможные проблемы и решения

### Проблема: Сервер не запускается после изменений

**Решение:**
```bash
# Проверить синтаксис
python -m py_compile main.py connection_manager.py

# Откатить если нужно
git reset --hard HEAD~1
docker-compose restart
```

### Проблема: Клиенты видят больше ошибок после обновления

**Решение:**
- Это нормально первые 1-2 часа (переходный период)
- Старые клиенты + новый сервер = может быть нестабильно
- Попросить всех обновить приложение

### Проблема: TURN серверы не работают

**Симптомы:**
```
Failed to gather candidates
ICE connection failed
```

**Решение:**
1. Проверить доступность TURN серверов:
```bash
telnet a.relay.metered.ca 80
telnet openrelay.metered.ca 80
```

2. Если не доступны - убрать из списка в `WebRtcManager.kt`
